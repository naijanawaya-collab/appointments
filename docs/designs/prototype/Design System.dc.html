Tokens, presets & components

One set of CSS variables, set per shop on the server in a single <style> tag inside <head>. No JS to theme, no flash. Existing names (--background … --danger) are kept; everything else derives from them.

Fluid type, space & layout

Every size is a clamp() between the 360px and 1440px viewports, so there are no breakpoint jumps for type. Layout switches with container queries on the section, not the page, so blocks work at any column width (editor preview, embeds, phones in landscape).

04

From one owner colour to a full, AA-safe palette

  1. Button text. Compute contrast of the accent against pure black and white; --accent-foreground = whichever is higher. Because the two curves cross at ≈ 4.58 : 1, one of them always passes AA — the button is never broken.
  2. Accent as text, links, outlines, focus ring. Check accent against --background. Below 4.5 : 1 → step OKLCH lightness by 0.02 (darker on light themes, lighter on dark) until it passes; store as --accent-text. Hue and chroma stay, so it still reads as “their” colour.
  3. States. hover = L ∓ 0.06, pressed = L ∓ 0.12, subtle tint = 12 % mix into background. All pure CSS relative colour.
  4. Dark mode. Same accent, re-checked against the dark background; usually lightened.
  5. Secondary. Only used decoratively (patterns, dividers, tag fill with foreground text) so it can never fail contrast.
  6. Editor warning. If step 2 had to move L by more than 0.15, the editor flags it and offers the corrected colour as a one-click fix.
